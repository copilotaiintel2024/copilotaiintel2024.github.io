Personal, self-hosted utility

Server backups.
Stored in your cloud.

VPS-Backup is a personal backup workflow designed to create recoverable copies of VPS projects, databases, and configuration files, and store them in the owner's Google Drive account.

Scheduled backups

Designed for automatic, periodic snapshots of selected server data.

Encrypted archives

Client-side encryption can be configured before backup data is uploaded.

Recovery focused

Stored versions can help restore files after mistakes or service failures.

How Google Drive is used

The application uses the Google Drive API through Rclone with the owner's consent. When configured, it uploads backup files, checks their presence, and manages old backups. Its intended operational use is limited to designated backup storage, even if a broader Drive permission has been granted.

This is not a public backup service. There are no sign-up forms, public accounts, or payment features on this website.
